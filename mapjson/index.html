Add MapJSON to Chrome

Chrome requires users to approve extensions. Until the extension is published on the Chrome Web Store, load the bundled folder locally.

  1. Open chrome://extensions.
  2. Turn on Developer mode.
  3. Click Load unpacked.
  4. Select the chrome-extension folder from this project.
